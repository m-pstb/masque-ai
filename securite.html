Comment ce site vous protège

Le texte que vous collez peut contenir des données sensibles. Le site est donc conçu pour qu'il ne puisse jamais quitter votre navigateur. Voici chaque protection, et la menace à laquelle elle répond.

Aucun serveur, aucun stockage

Menace : une base de données piratée, un historique qui fuit.

Le texte est analysé sur votre appareil. Il n'est ni envoyé, ni enregistré : fermer l'onglet l'efface. Le site n'utilise ni cookie, ni stockage local, ni outil de statistiques.

Politique de sécurité du contenu (CSP)

Menace : un script malveillant injecté qui lirait votre texte et l'enverrait ailleurs.

Une règle placée en tête de chaque page interdit au navigateur de charger quoi que ce soit venant d'un autre site, et bloque toute connexion réseau depuis le JavaScript (connect-src 'none'). Même un code injecté ne pourrait rien envoyer.

Protection contre l'injection de code (XSS)

Menace : un texte collé contenant du code qui s'exécuterait dans la page.

Le texte est toujours affiché comme du texte, jamais interprété comme du code : le site n'utilise pas innerHTML. La directive require-trusted-types-for 'script' fait bloquer par le navigateur toute tentative de l'utiliser.

Zone de saisie protégée

Menace : un correcteur orthographique en ligne qui recevrait votre texte.

Le correcteur et la saisie automatique sont désactivés (spellcheck="false", autocomplete="off"), et la taille du texte est limitée (maxlength).

Aucune dépendance externe

Menace : une bibliothèque ou une police hébergée ailleurs, modifiée par un pirate.

Pas de bibliothèque JavaScript. Les polices et les images sont hébergées dans le site lui-même. Moins de code tiers, moins de risque.

Liens sortants sécurisés

Menace : une page ouverte dans un nouvel onglet qui prendrait le contrôle de celui-ci.

Les liens externes utilisent rel="noopener noreferrer", par exemple ce lien vers le site de l'ANSSI.

Limites connues

  • Les noms, prénoms et adresses postales ne sont pas détectés.
  • Seuls les formats français sont reconnus (IBAN FR, téléphones 0X ou +33).
  • L'hébergement GitHub Pages ne permet pas de configurer les en-têtes serveur X-Frame-Options, X-Content-Type-Options et frame-ancestors, qui ne fonctionnent pas dans une balise <meta>.
